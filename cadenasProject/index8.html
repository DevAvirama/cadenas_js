String padEnd

¿Que es?:

Es un método de JavaScript que permite tomar una cadena y completarla por el lado derecho con un texto de relleno hasta alcanzar una longitud total que tú decidas. Si la cadena ya es igual o más larga que esa longitud, no la cambia. Su función principal es formatear texto para que mantenga un ancho fijo al mostrarse, lo cual es útil cuando haces tablas, listados, reportes o interfaces donde todo debe quedar alineadito. Este método no modifica el string original (porque los strings son inmutables), sino que devuelve una nueva cadena con el relleno aplicado.

Sintaxis

cadena.padEnd(longitud, relleno)
