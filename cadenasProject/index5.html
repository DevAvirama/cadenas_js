String padStart

Que es:

Es un método que añade caracteres al inicio de una cadena para que alcance una longitud especifica. Este relleno se realiza desde el principio de la cadena (lado izquierdo) y devuelve una nueva cadena sin modificar la original. Es útil para formatear, por ejemplo, alinear números añadiendoles ceros o espacios iniciales.

Sintaxis

string.padStart(longitudTotal, caracterRelleno)
