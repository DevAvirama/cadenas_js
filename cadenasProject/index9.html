Strings Repeat

El método string.repeat() es una función de JavaScript que permite tomar una cadena de texto existente y crear una nueva cadena repitiendo el contenido tantas veces como se indique. Este método no modifica la cadena original, sino que genera una nueva. Es útil cuando necesitas duplicar palabras, crear patrones, generar líneas decorativas o producir texto repetitivo de forma automática, sin escribirlo varias veces manualmente. Además, solo acepta números enteros y positivos; si intentas usar números negativos o no válidos, JavaScript mostrará un error.d

Sintaxis

cadena.repeat(veces).
