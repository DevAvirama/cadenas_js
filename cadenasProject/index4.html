Metodo String Replace para Javascript

¿Que es?

Es un método de JavaScript que permite reemplazar parte de un texto por otro. Funciona sobre cadenas (strings) y retorna una nueva cadena modificada

¿Para que Sirve?

  • Corregir textos automáticamente.
  • Modificar frases o palabras al vuelo.
  • Limpiar datos recibidos de formularios.
  • Aplicar formatos y patrones.
